# 🏠 Old-Home

لوحة عربية لإدارة خادمك (منزلي أو سحابي): **aaPanel + Cloudflare Tunnel** من واجهة واحدة.
تنشر مواقعك على دوميناتك **بدون فتح أي منفذ في الراوتر**، وبدون أوامر.

> ⚠️ **إخلاء مسؤولية:** المشروع يعمل بصلاحية root ويعدّل إعدادات الخادم وسجلات DNS في Cloudflare.
> يُقدَّم **كما هو، بدون أي ضمان** (انظر [LICENSE](LICENSE)). جرّبه أولاً على خادم تجريبي، واحتفظ بنسخ احتياطية لمواقعك.

## ⚡ البدء السريع (10 دقائق)

**المتطلبات:** جهاز عليه **Ubuntu Server 24.04** نظيف (مختبر)، و**حساب Cloudflare** فيه دومين واحد على الأقل.

### 1. أمر واحد بعد تثبيت Ubuntu
```bash
curl -fsSL https://raw.githubusercontent.com/ahmdeeicode/old-home-server/main/bootstrap.sh | sudo bash
```
يفعّل SSH، ويطلب **كلمة مرور جديدة لحساب root** ويسمح له بالدخول عبر SSH (مع حماية **fail2ban**: 5 محاولات خاطئة ← حظر ساعة)، ثم يثبّت اللوحة.
في النهاية يطبع **رابط اللوحة وكلمة مرورها**.

### 2. افتح اللوحة
`https://<عنوان-الخادم>:8443` ← في أول مرة: **Advanced ← Proceed** (شهادة ذاتية) ← ادخل بكلمة المرور.
**أول شيء: الإعدادات ← تغيير كلمة مرور اللوحة.**

### 3. ثبّت aaPanel من الواجهة
**التثبيت** ← انسخ أمر **Ubuntu/Debian** من [aapanel.com](https://www.aapanel.com/new/download.html) والصقه ← **تثبيت aaPanel**.
تشاهد التقدم مباشرة، وفي النهاية تظهر بيانات الدخول. ثم ادخل aaPanel وثبّت **LNMP** (اختر Fast).

### 4. اربط دومينك
**الدومينات** ← **ربط دومين** ← افتح رابط التفويض ← اختر الدومين في Cloudflare ← **Authorize** ← **ربط**.

### 5. أضف الروابط والمواقع
- **الدومينات ← روابط هذا الخادم:** روابط لـ **SSH** و**aaPanel** و**اللوحة نفسها** (زر **طريقة الاتصال** يشرح إعداد PuTTY)
- **المواقع ← إضافة موقع:** يُنشأ الموقع في aaPanel ويُنشر على دومينك بنقرة واحدة

> بعد إضافة أي رابط أو موقع انتظر **~30 ثانية** قبل فتحه (قد تظهر Error 1033 مؤقتاً).

## ✨ المزايا
| | |
|---|---|
| **الرئيسية** | المعالج والذاكرة والقرص والحرارة، وحالة الخدمات والتونلات، وإعادة التشغيل |
| **التثبيت** | aaPanel بلصق الأمر الرسمي (لا يُنفَّذ النص الملصوق: يُستخرج رابط `www.aapanel.com/script/*.sh` فقط) |
| **المواقع** | إضافة، ونشر، وإلغاء نشر، وحذف. اكتشاف Force HTTPS وإصلاحه تلقائياً |
| **الدومينات** | عدة حسابات Cloudflare، لكل حساب تونل مستقل. روابط SSH وaaPanel واللوحة |
| **السجلات** | التونلات وNginx وكل موقع |
| **الإعدادات** | تغيير كلمة المرور، والوصول المباشر (مغلق / محلي / عام)، وعناوين IP الحقيقية، و**تحديث اللوحة بنقرة** |

## 🔄 التحديث
من **الإعدادات ← تحديث اللوحة**، أو أعد تشغيل أمر البدء السريع (لن يطلب كلمة مرور root مرة أخرى).

## 🗑️ الإزالة
```bash
sudo bash /opt/oldhome/uninstall.sh          # اللوحة فقط — المواقع والتونلات تبقى تعمل
sudo bash /opt/oldhome/uninstall.sh --full   # + حذف التونلات وسجلات DNS التي أنشأتها اللوحة
```
يعرض الخطة أولاً، ويطلب `yes`، ويحفظ نسخة احتياطية في `/root/oldhome-backup-*.tar.gz`.
**لا يمس aaPanel ولا المواقع ولا قواعد البيانات.**

## 🔐 الأمان
- اللوحة تستمع على `127.0.0.1:8800` و(حسب الإعداد) `0.0.0.0:8443` عبر HTTPS
- الدخول يُحظر **15 دقيقة** بعد 5 محاولات خاطئة (بعنوان الزائر الحقيقي، حتى عبر التونل)
- تغيير كلمة المرور يُخرج كل الأجهزة الأخرى
- رابط اللوحة عبر الدومين: محمي بـ **Cloudflare Access** (موصى به)، أو بكلمة المرور فقط (اختيارك)
- لا يُنشأ سجل DNS إلا إذا كان الاسم **غير مستخدم**، ولا يُحذف إلا إذا كان يشير إلى **تونل هذا الخادم**
- لا قواعد `*` (wildcard) إطلاقاً
- **لا أسرار في هذا المستودع:** كل المفاتيح وكلمات المرور تبقى على خادمك فقط

## 🛠️ تفاصيل تقنية
<details><summary>للمطورين</summary>

| المسار | الوظيفة |
|---|---|
| `bootstrap.sh` | الأمر الأول: SSH، وroot، وfail2ban، وتنزيل المشروع، وتثبيت اللوحة |
| `install.sh` | التثبيت والتحديث (آمن للتكرار). `--check` فحص للقراءة فقط |
| `uninstall.sh` | الإزالة |
| `manager/app.py` | Flask API + الحماية (Access JWT / الوضع المباشر / الحظر) |
| `manager/core/cf.py` | توليد إعداد التونل، وسجلات DNS |
| `manager/core/aapanel.py` | API الخاصة بـ aaPanel (مقيّدة بـ 127.0.0.1) |
| `manager/core/installer.py` | تثبيت aaPanel من الأمر الرسمي |
| `manager/core/direct.py` | الوصول المباشر على 8443 |
| `manager/core/updater.py` | التحديث من GitHub |

**الإعدادات على الخادم (خارج المستودع):**
`/etc/oldhome/` (state.json، وكلمة المرور، والشهادة، ومفتاح API) و`/etc/cloudflared/<حساب>/` (cert.pem، ومفتاح التونل، وconfig.yml المولَّد).

**التثبيت اليدوي:**
```bash
sudo git clone https://github.com/ahmdeeicode/old-home-server.git /opt/oldhome
sudo bash /opt/oldhome/install.sh --check   # فحص فقط
sudo bash /opt/oldhome/install.sh           # تثبيت (يثبّت aaPanel تلقائياً إن لم يوجد)
```
على خادم عليه aaPanel مسبقاً: لا يُعاد تثبيته، ويُعاد استخدام مفتاح API إن وُجد.
